사각형을 제대로 찾지 못하는 경우가 있으니 다음 기능을 추가
1. 사각형 이미지를 자동으로 찾지 못해서 실패하거나 사각형을 찾더라도 사용자에게 사각형 이미지에 대해서 피드백을 받아서 사용자가 다시 사각형을 설정하기 원하면 다시 설정하게 변경
2. 사각형 이미지를 사용자에게 입력 받는 방식은 4개의 코너를 사용자가 마우스로 클릭해서 사각형 꼭지점을 형성하게 설정함.
3. 사용자에게 입력된 꼭지점 정보로 그려진 사각형 이미지를 사용자에게 보여주고 최종 확인 후 사용. 최종 확인 시 사용자 Fail이라고 결정하면 사각형 꼭지점 정보를 다시 입력 받는다.
